# RuneHTML Test Suite

Unit tests for the RuneHTML game.

## Setup

Install dependencies:
```bash
npm install
```

## Running Tests

```bash
# Run all tests
npm test

# Run tests in watch mode
npm run test:watch

# Run tests with coverage
npm run test:coverage
```

## Test Files

- `tests/skills.test.js` - Skills system tests (exp, levels)
- `tests/combat.test.js` - Combat mechanics tests (HP, damage)
- `tests/gameState.test.js` - Game state management tests
